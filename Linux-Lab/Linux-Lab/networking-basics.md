# Networking Basics

## Overview

Networking is an important foundation of cybersecurity. This lab documents basic networking concepts and commands.

## Key Concepts

- IP Address — identifies a device on a network.
- DNS — translates domain names into IP addresses.
- Port — identifies a network service.
- TCP/IP — a set of protocols used for communication across networks.

## `ping`

The `ping` command can be used to test whether a host is reachable and measure network response time.

Example:

ping 127.0.0.1

## Learning Objective

Build a basic understanding of networking concepts before progressing to network security and ethical hacking.
