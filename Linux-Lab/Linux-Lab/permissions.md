# Linux File Permissions

## Overview

Linux file permissions control who can read, write, or execute files and directories.

## `ls -l`

The `ls -l` command displays detailed information about files and their permissions.

Example:

ls -l

## Permission Types

- `r` = Read
- `w` = Write
- `x` = Execute

## `chmod`

The `chmod` command is used to change file permissions.

Example:

chmod 644 test.txt

## Learning Objective

Understand how Linux permissions work and how they help protect files and directories.
